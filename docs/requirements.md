# 真人漫剧爆款视频归纳+二创全流程 - 需求文档

## 一、项目背景

面向短视频内容创作者，提供一套"分析爆款 → 提取模式 → 二创生成"的完整工具链，降低漫剧（动漫风格短剧）创作门槛，提高内容产出效率。

## 二、核心目标

系统需要具备**双轨并行**能力：

### 轨道一：爆款分析

从已有爆款视频中提取可复用的资产和模式：

1. **内容基因提取**：识别视频的叙事结构（三幕剧/反转递进/金句串烧）、情绪节拍分布、套路标签、台词密度
2. **视觉基因提取**：分析画面比例、平均镜头时长、景别分布序列、色调方案、文字贴纸覆盖率
3. **音频基因提取**：识别 BGM 风格和 BPM、音效触发时机、语速节奏
4. **流量基因提取**：分析开头钩子类型和时长、留存率波峰位置、结尾引导风格

5. **分析结果结构化存储**：以上分析结果需以统一 JSON 格式存储，支持跨赛道比较和相似检索

6. **支持赛道内和跨赛道归纳**：同赛道内找共性模式，跨赛道复用节奏/视觉风格

### 轨道二：从零创作

不依赖爆款分析，直接生成完整漫剧：

1. **选题构思**：选择赛道（都市甜宠/悬疑/古装/等）、主题、时长
2. **剧本生成**：基于选题，由 AI 生成包含场景、台词、情绪的完整剧本
3. **人设设计**：生成角色外貌、性格描述和多表情立绘
4. **分镜设计**：将剧本拆解为分镜帧，包含景别、机位、角色位置/表情、背景、对应台词
5. **视频合成**：将分镜、立绘、TTS 语音、BGM、音效、字幕合成为竖屏视频
6. **文案生成**：基于成片生成发布用标题、简介、话题标签

### 轨道三（混合模式）：分析驱动的创作

1. 上传爆款视频 → 系统分析提取基因
2. 用户选择继承哪些维度（节奏、视觉、叙事等）
3. 修改赛道/主题
4. 系统基于混合模板生成新剧本 → 人设 → 分镜 → 成片

| 编号 | 需求 | 优先级 |

## 四、非功能性需求

| 编号 | 需求 | 说明 |
|------|------|------|
| NF-01 | LLM 调用可靠性 | 支持重试（最多3次）、熔断降级、超时处理 |
| NF-02 | 视频合成异步处理 | 不在 HTTP 请求线程内执行，使用任务队列 |
| NF-03 | 数据持久化 | 所有创作数据可持久保存，支持恢复继续 |
| NF-04 | 文件存储 | 视频/图片/音频使用对象存储（MinIO），不使用数据库 |
| NF-05 | 可部署性 | 提供 Docker Compose 一键部署 |
| NF-06 | 接口规范 | RESTful API，前后端通过 OpenAPI 生成类型 |

## 五、用户角色

| 角色 | 描述 |
|------|------|
| 内容创作者 | 主要用户，使用系统分析爆款和生成漫剧 |
| 系统管理员 | 管理素材库、系统配置 |

## 六、技术约束

1. 后端语言：Java（用户熟悉）
2. 框架：Spring Boot
3. AI 服务：通过 HTTP 调用国产大模型 API
4. 视频处理：FFmpeg
5. 部署方式：Docker Compose
